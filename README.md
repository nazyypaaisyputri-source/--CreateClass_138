# CreateClass_138

Tugas Praktikum **Class dan Object menggunakan Python**.

## Penjelasan Kode

### 1. File `persegi_panjang.py`

File ini berisi class `PersegiPanjang` yang digunakan sebagai dasar untuk membuat objek persegi panjang.

Di dalam class ini terdapat beberapa bagian:

* **`__init__(self, panjang, lebar)`**: Digunakan untuk menentukan nilai panjang dan lebar saat objek dibuat.
* **`keliling(self)`**: Digunakan untuk menghitung keliling persegi panjang.
* **`luas(self)`**: Digunakan untuk menghitung luas persegi panjang.
* **`__str__(self)`**: Digunakan untuk menampilkan informasi dari objek dalam bentuk teks.

### 2. File `main.py`

File ini digunakan untuk menjalankan program. Pada file ini dibuat objek `PersegiPanjang` dengan panjang **3 cm** dan lebar **2 cm**. Setelah itu, program menampilkan hasil perhitungan keliling dan luas persegi panjang.

## Cara Menjalankan

Untuk menjalankan program, buka terminal pada folder project lalu ketik:

```bash
python main.py
```

## Hasil output
persegi panjang, panjang 3 cm, dan lebar 2 cm
Keliling: 10 cm
Luas: 6 cm²
